3.  The morphological analysis (`pos`, `analysis`, `segmentation`) is performed on this identified primary word.
4.  A detailed note is included in the `evidence` section for each affected token, explicitly stating that the token is a concatenation, identifying the likely constituent words, and explaining the assumptions made (e.g., character corrections like `¡` -> `አ`).
